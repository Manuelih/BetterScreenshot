# Commands

All commands are client-side: they work on any server and don't need permissions.

| Command | Description |
| --- | --- |
| `/betterscreenshot upload <file>` | Uploads a screenshot from your `screenshots` folder |
| `/betterscreenshot copy <file>` | Copies a screenshot image to the clipboard |
| `/betterscreenshot reload` | Reloads `config/betterscreenshot.json` |

`<file>` is the file name only, for example:

```
/betterscreenshot upload 2026-10-23_14.03.37.png
```

{% hint style="info" %}
The **\[Upload]** and **\[Copy]** buttons in chat run these commands for you.
{% endhint %}
