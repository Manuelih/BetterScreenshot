# How to use

## 1. Take a screenshot

Press **F2** (or whatever key you set for *Take Screenshot* in the controls). The screenshot is saved in your `screenshots` folder like in vanilla, and this message appears in chat:

<figure><img src="../.gitbook/assets/gallery-1-buttons.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
To click the buttons, open the chat with **T**.
{% endhint %}

## 2. Choose what to do

### \[Upload]

Uploads the screenshot to the configured host ([catbox.moe](https://catbox.moe) by default) and copies the link to your clipboard.

<figure><img src="../.gitbook/assets/gallery-2-uploaded.png" alt=""><figcaption></figcaption></figure>

The chat message contains:

* the **link**: click it to open the image in your browser
* **\[Copy link]**: copies the link again
* **\[Retry]**: shown only if the upload fails

### \[Copy]

Copies the **image** to your clipboard. Then just press **Ctrl+V** in Discord, Telegram, Paint, Photoshop...

## Clicking the file name

The underlined file name still works like in vanilla: it opens the screenshot on your computer.
