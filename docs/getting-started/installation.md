# Installation

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for your Minecraft version (1.21.8, 1.21.9, 1.21.10 or 1.21.11).
2. Download [Fabric API](https://modrinth.com/mod/fabric-api) for the same Minecraft version.
3. Download [Better Screenshot](https://modrinth.com/mod/betterscreenshot/versions).
4. Put both `.jar` files in your `.minecraft/mods` folder.
5. Start the game with the Fabric profile.

{% hint style="info" %}
Better Screenshot is **client-side only**. You don't need to install it on servers, and it works on any server, including vanilla ones.
{% endhint %}

{% hint style="info" %}
Using a launcher like Modrinth App, Prism Launcher or CurseForge? Just search for **Better Screenshot** and add it to a Fabric instance: Fabric API is installed automatically.
{% endhint %}

## Linux only

The **\[Copy]** button uses the system clipboard tools. On Linux install one of these:

| Session | Package |
| --- | --- |
| Wayland | `wl-clipboard` |
| X11 | `xclip` |

Windows and macOS don't need anything extra.
