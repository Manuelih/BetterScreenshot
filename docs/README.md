# Better Screenshot

<figure><img src=".gitbook/assets/gallery-1-buttons.png" alt=""><figcaption><p>The screenshot message with the Upload and Copy buttons</p></figcaption></figure>

**Better Screenshot** is a client-side Fabric mod that upgrades the vanilla screenshot message.

When you press **F2** the screenshot is saved exactly like in vanilla, but the chat message gets two buttons:

| Button | What it does |
| --- | --- |
| **\[Upload]** | Uploads the screenshot online and copies the link to your clipboard |
| **\[Copy]** | Copies the image itself to your clipboard, ready to paste into Discord, Telegram, Paint... |

Nothing is uploaded unless you click **\[Upload]**.

## Supported versions

| Minecraft | Loader | Requires |
| --- | --- | --- |
| 1.21.8 - 1.21.11 | Fabric | [Fabric API](https://modrinth.com/mod/fabric-api) |
